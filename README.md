# 📑 Lista de Contactos

Aplicación web desarrollada como proyecto de práctica para reforzar
conceptos de **HTML, CSS y JavaScript puro**, sin uso de frameworks.

Permite gestionar una agenda de contactos con diferentes estados
(favoritos, generales y bloqueados).

## ✅ Características
- Añadir, editar y eliminar contactos
- Validación de formularios:
  - Campos obligatorios
  - Formato de teléfono válido
  - Prevención de números duplicados
- Clasificación de contactos:
  - ⭐ Favoritos
  - 👤 Generales
  - 🚫 Bloqueados
- Información del último contacto añadido
- Interfaz clara y organizada en paneles

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (ES6)

## 📋 Uso
1. Introduce el nombre y el teléfono del contacto
2. Pulsa **Añadir** para guardarlo en la agenda
3. Haz clic sobre un contacto para editarlo
4. Usa los iconos para:
   - Marcar como favorito
   - Pasar a general
   - Bloquear
   - Eliminar
5. Consulta el último contacto añadido en la parte inferior

## 🔧 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Rusby6/lista-contactos
   ```

2. Accede al directorio del proyecto:
   ```bash
   cd lista-contactos
   ```

3. Abre el archivo `index.html` en tu navegador.
